# Research Reports

本目录保存来自 `tests/research` 或其他探索性工作的可审查摘要。研究报告用于解释实现选择和记录未决问题；它们不构成 production policy、服务性能或发布资格的证据。

需要归档时使用：

```text
docs/research_reports/<yyyy-mm-dd>/<study>/<machine-id>/research_report.md
```

报告应记录 Git revision、研究问题、输入和机器环境、命令、观察结果、局限性及后续验证。任何需要影响 numerics policy 或 threshold 的结论，都必须另行按 [benchmark report convention](../conventions/benchmark.md) 生成正式 benchmark 摘要。
